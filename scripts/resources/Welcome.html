This installs Apple's cctools 1035.1.102 and ld64 957.1 (ld, as, lipo, otool, nm, libtool, install_name_tool and the rest), built to run on Mac OS X 10.9 (Mavericks) and later, Intel and Apple Silicon alike, into /usr/local/mavergreen/cctools/. It needs no Command Line Tools.

Open a new Terminal window: the tools are on your PATH. Your shell searches /usr/bin first, so a bare ld still finds Apple's: call /usr/local/mavergreen/cctools/bin/ld, or put that directory first.

A background updater (Sparkle) checks daily for new releases. Built from tpoechtrager's cctools-port of Apple's open source, with the changes and recipe at github.com/Mavergreen/cctools, where every release also carries the source it was built from.
